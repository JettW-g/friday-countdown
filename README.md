# 下班倒计时 · Countdown Terminal

一个具有工业赛博朋克风格的「下班倒计时」网页，实时显示距离最近周五 18:00 的剩余时间。

## 功能说明

| 状态 | 时间范围 | 表现 |
|------|----------|------|
| 倒计时进行中 | 周一 00:00 ~ 周五 18:00 | 黄色数字滚动倒计时，显示 xx天xx时xx分xx秒 |
| 自由时间 | 周五 18:00 ~ 周日 23:59 | 数字归零变灰，显示"自由时间"遮罩 |
| 自动重置 | 周一 00:00 | 倒计时自动重新开始计算 |

## 设计特色

- **翻牌机械滚动数字**：每位数字独立滚动，CSS `transform: translateY` 平滑过渡动画
- **琥珀黄 + 深空黑**配色，扫描线纹理与噪点叠加，复古 CRT 显示器质感
- **Bebas Neue** 超窄展示字体 + **Share Tech Mono** 等宽终端字体
- 底部**本周进度条**实时显示从周一到周五 18:00 的完成百分比
- 纯原生 HTML / CSS / JavaScript，无任何依赖，直接打开即用

## 使用方法

直接用浏览器打开 `index.html` 即可，无需任何构建步骤。
